# How Pecus Works with LedgerMind

**Pecus** is an AI teammate that can automate tasks, answer questions, and help manage workflows within connected tools like GitHub. When integrated with the LedgerMind repository, here's what Pecus can do for your project:

## Key Features
- **Issue and Pull Request Automation**: Pecus can create, update, and comment on issues and pull requests via conversations or scheduled routines.
- **Context-Aware Actions**: It understands requests in natural language and acts directly in the repository after your approval.
- **Works in Slack & Web**: Trigger Pecus using Slack commands, direct messages, or from the web interface.
- **Fact-Based Answers**: Pecus reads repository issues, pull requests, and metadata to answer your questions using real data.
- **Routine Automation**: Save common tasks as routines (like nightly health checks or issue triage), which Pecus can run on a schedule.

## Example Interactions
- "Create a new issue for a bug found during review"
- "Update README to mention project contributors"
- "List all open pull requests with a label 'urgent'"
